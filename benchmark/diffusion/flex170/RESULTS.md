# 双 Flex 170 生图结果

Qwen Base 的完整 40 步去噪在 INT8 下耗时约 18.09 秒，BF16 为 28.52 秒。MOSS 的三种仅编码器量化方案都保留 BF16 DiT，去噪耗时集中在 50.43–50.45 秒，单图 SSIM 的差别更明显。

|---|---:|---:|---:|---|---:|---:|
| `base-bf16` | 40 × 2 | 28.518 / 28.513 | 29.045 | BF16 | 46.33 / 46.34 | 1.0000 |
| `turbo-bf16` | 8 × 3 | 5.785 / 5.781 | 6.316 | BF16 | 45.71 / 45.74 | 1.0000 |
| `base-int8` | 40 × 2 | 18.089 / 18.084 | 18.646 | INT8 | 63.23 / 63.24 | 0.9603 |
| `turbo-int8` | 8 × 3 | 4.024 / 4.018 | 4.594 | INT8 | 56.89 / 56.98 | 0.9805 |

BF16 单位为 TFLOP/s，INT8 单位为 TOPS。每次乘加计两次运算。分子取独立诊断请求中该精度的实际矩阵运算形状及次数，注意力按稠密等效算量折算。INT8 行只计 INT8 工作量。分母为含通信与等待的同步去噪墙钟。HTTP 从本机发送请求计至收到 PNG。表中 SSIM 按 RGB8、三个通道、取值范围 255 计算，每种模型使用一个提示词和种子 42。逐请求时间、两卡算量和 SSIM 可直接复算。[逐请求记录](measurements.csv) · [同权重参考图的 RGBA SHA-256](cases.json)

**Qwen-Image-2.1** 使用 1024×1024 帆船提示词、CFG 1、TP2、FA、空间切分 VAE 和条件缓存。DiT 时间按卡 0 / 1 并列。两组 INT8 的 DiT、文本编码器、词嵌入和 VAE 驻留显存，冷请求实际执行编码器。四组完整记录来自 SGLang `.18` 和内核 `.7`，同权重参考图逐像素一致。四组均低于 BF16 每卡 55 TFLOP/s 或 INT8 每卡 70 TOPS 的验收目标。`.19` 安装版在任务暂停时只留下部分请求记录。[四组对应的 SGLang 提交](https://github.com/gesong2077/sglang/commit/00363f09ce98f0c1b207d67bb819fde02e45868b) · [内核提交](https://github.com/gesong2077/sgl-kernel-xpu/commit/e7a897c12eb85e11c826cf3eb4541d3704f2a3a7)

**P2P 对照**一个独立的 Turbo BF16 服务，8 个热请求交错使用原始 BF16 传输与无损指数打包，两种设置各 4 次。卡 0 的平均整段 DiT 从 5.773 降至 5.670 秒，卡 1 从 5.770 降至 5.666 秒，8 张图与同权重参考逐像素一致。该实验使用候选通信库。

**MOSS-Image-SFT** 使用 768×768 茶壶提示词、Euler、CFG 3、flow shift 5，TP1、双卡 CFG 并行、torch SDPA，禁用条件缓存，文本编码器逐层卸载。`both` 使用 ConvRot DiT 和编码器，`comfy`、`rtn`、`gptq` 分别只量化编码器。每组第一轮前空闲 180 秒，紧接着运行第二轮。两轮中两卡的热限频采样均为零。每次取两卡较长的 DiT 时间，再对请求求均值。[五组对照对应的 SGLang 提交](https://github.com/gesong2077/sglang/commit/19af8e752dd09e4d6703b047887b3fef0a4f4a3d)

**单独的内核对照** 使用 Base BF16 第 2 步第 5 层的真实 Q/K/V，Xe-Forge 正反两种顺序交错计时。专用 FA 在卡 0 为 2.06 / 2.14 ms，在卡 1 为 2.07 / 2.22 ms；oneDNN micro_sdpa 分别为 5.66 / 5.88 ms 和 5.72 / 5.99 ms。每个内核每卡有 11 个有效 OA 派发记录，XMX 活跃率分别为 FA 37.10% / 37.03%、oneDNN 10.17% / 10.19%。同输入最大绝对差为 0.015625。MOSS 原版另一次 50 步 FA 后端对照中，优化 FA 的平均 HTTP 为 43.279 秒，oneDNN 为 43.927 秒，两者的 RGB SSIM 为 0.943544。[逐内核采集和回放方法](README.md#用-xe-forge-回放注意力)
